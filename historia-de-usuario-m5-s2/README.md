# Proyecto Login Modular con React + TypeScript

## Instalación

```bash
npm install
npm run dev
```

## Funcionalidades

- Login modular con validación
- Redirección tras autenticación
- CRUD de usuarios con logs simulados
- Decorador que agrega metadata automáticamente

## Pruebas

- Usuario: admin / 1234
- Usuario: juan / abcd

## Estructura

- components → UI
- utils → lógica
- data → mock data
- interfaces → tipos

## Notas

- Se usa TypeScript con tipado estricto
- Decoradores habilitados en tsconfig
